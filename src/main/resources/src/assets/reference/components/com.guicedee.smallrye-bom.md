**Centralised version management** for the entire [GuicedEE](https://guicedee.com) ecosystem — import this single BOM to align all GuicedEE core modules, integrations, and third-party wrappers at compatible versions without hardcoding any version strings in your project.

The BOM manages `com.guicedee:hazelcast` at the GuicedEE release version for cache-only and Vert.x clustering projects generated by the website builder and IntelliJ plugin.

Built on [Maven BOM](https://maven.apache.org/guides/introduction/introduction-to-dependency-mechanism.html#bill-of-materials-bom-poms) — [GuicedEE](https://guicedee.com) — Java 25+

## Installation

### Maven

```xml
<dependencyManagement>
  <dependencies>
    <dependency>
      <groupId>com.guicedee</groupId>
      <artifactId>guicedee-bom</artifactId>
      <version>${guicedee.version}</version>
      <type>pom</type>
      <scope>import</scope>
    </dependency>
  </dependencies>
</dependencyManagement>
```

Then declare dependencies without versions:

```xml
<dependency>
  <groupId>com.guicedee</groupId>
  <artifactId>vertx</artifactId>
</dependency>
```

<details>
<summary>Gradle (Kotlin DSL)</summary>

```kotlin
dependencies {
    implementation(platform("com.guicedee:guicedee-bom:2.4.1"))

    implementation("com.guicedee:vertx")
    // no version needed — managed by the platform
}
```
</details>

## 🚀 Features

- **Single import** — one `<scope>import</scope>` declaration manages versions for the entire GuicedEE platform
- **Ecosystem-wide alignment** — core, CDI, persistence, Vert.x, REST, messaging, and third-party wrappers all move in lockstep
- **No version conflicts** — guarantees that all GuicedEE modules are compiled and tested together
- **Includes nested BOMs** — automatically imports `apache-bom`, `fasterxml-bom`, `standalone-bom`, `jakarta-bom`, `google-bom`, and `tests-bom`
- **Works with JWebMP** — designed to be imported alongside `jwebmp-bom` for full-stack UI projects

## 🤝 Companion BOMs

For full-stack projects, import these BOMs alongside the GuicedEE BOM:

```xml
<dependencyManagement>
  <dependencies>
    <!-- GuicedEE platform (Guice, Vert.x, Jackson, etc.) -->
    <dependency>
      <groupId>com.guicedee</groupId>
      <artifactId>guicedee-bom</artifactId>
      <version>${guicedee.version}</version>
      <type>pom</type>
      <scope>import</scope>
    </dependency>

    <!-- JWebMP UI modules -->
    <dependency>
      <groupId>com.jwebmp</groupId>
      <artifactId>jwebmp-bom</artifactId>
      <version>${guicedee.version}</version>
      <type>pom</type>
      <scope>import</scope>
    </dependency>
  </dependencies>
</dependencyManagement>
```
